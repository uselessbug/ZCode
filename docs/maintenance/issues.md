# 独立 Web 与移动端适配问题清单

本文是独立 Web 与移动端适配问题的唯一维护入口，按用户可见症状记录当前状态。

## 实机验证未通过 -> 已撤回适配，待新版部署验证（1 项）

1. **技能详情“打开路径”打开服务器目录（3.1，Web 暂不支持）**
   - **症状**：在「设置 -> 技能」点击技能路径时调用本机文件管理器，独立 Web 下原本不支持；此前尝试改为打开右侧「文件管理」栏，2026-11-12 实机验证发现能打开右栏但无法定位到技能目录。
   - **已确认根因**：文件树仍以当前项目为根，技能目录在项目外，因而定位被跳过。
   - **状态**：已撤回适配，待新版部署验证（`SkillsSection` 局部回退），**不计为功能已修复，独立 Web 暂不支持技能打开路径**（退回原本地文件管理器调用与失败提示，并撤回无项目时的目录浏览弹窗；技能页“当前服务器”范围文案等其余功能保留）。工作区文件搜索 `.zcodeignore`「打开文件位置」定位的就是当前项目根目录本身，保留未回退（单列见下方）。

## 待确认与集中复核（3 项）

1. **新建任务与归档任务的工作区归属一致性（集中复核）**
   - **症状**：非已证实故障；需结合项目多目录、非项目草稿与任务跨项目移动改动，集中复核新建任务、归档与取消归档在独立 Web 下的 `cwd`、Git 归属、`workspacePath` 与 `workspaceIdentity` 一致性。
   - **状态**：待复核（本轮未确认具体异常触发链，未作盲目修改）。

2. **输入法剪贴板长文本粘贴是否转为附件**
   - **症状**：粘贴超过阈值（15360 字符）的文本时，系统原生剪贴板路径已确认转为附件；使用输入法剪贴板粘贴 16000 字符样本时，消息中收到样本正文，同时同条消息附带一份 15999 字符文本附件（相对 16000 字符样本仅缺少末尾一个换行，未确认该附件来自系统剪贴板测试还是输入法剪贴板测试）。
   - **状态**：待确认。仅凭收到消息正文不能判定输入法剪贴板转附件失败，需结合输入框附件状态进一步确认。

3. **实际手机重连后的软键盘与输入焦点表现**
   - **症状**：断线重连后恢复原编辑器焦点与选区的逻辑已上线，但移动浏览器对程序化唤起软键盘有系统限制，实体手机重连后的焦点与键盘交互表现有待验证。
   - **状态**：待确认（需实体手机实测反馈）。

## 待评估建议与暂缓项（2 项）

1. **设置页“记忆”列表项菜单直接提供编辑入口（暂不做）**
   - **说明**：记忆文件点击查看、页内编辑与保存已可用；用户确认后端无删除接口则不做删除功能（需删除时让对话 Agent 删除，尽量少改后端），已取消新增删除接口需求；列表菜单直接“编辑”入口暂不做（若未来需要再另行评估）。
   - **状态**：暂不做（本轮不实施）。

2. **插件交互页（UI Plugin）独立 Web 承载**
   - **症状**：依赖宿主专属容器的插件自定义交互页面在独立 Web 下尚未提供通用承载入口。
   - **状态**：暂缓（低优先级，待实际使用需求明确后再评估）。

## 已修复

- **插件市场从服务器目录添加插件来源**
  - **症状**：在「插件市场 -> 添加来源」点击「选择目录」时调用电脑本地文件夹选择器，独立 Web 下无法浏览并选择服务器上的插件源目录。
  - **状态**：已修复（2026-11-12 实机验证通过：可在「添加来源」弹窗中浏览服务器目录并添加插件来源）。
- **工作区文件搜索 `.zcodeignore`「打开文件位置」**
  - **症状**：在「设置 -> 工作区文件搜索」生成或保存 `.zcodeignore` 后点击「打开文件位置」时调用电脑本地文件管理器。
  - **状态**：已实现并单列保留（目标路径即为当前项目根目录，点击后打开右侧「文件管理」栏定位到项目根目录，未随 3.1 技能路径回退）。
- **任务移入项目、跨项目移动与项目多目录（多 root）限制**
  - **症状**：独立 Web 下无目录自动分配与单目录新建项目已可用，但为项目添加或编辑多个目录、将无项目会话移入项目，或在项目之间移动任务时，仍被远程单目录与目录不可变策略拦截。
  - **状态**：已修复（2026-11-12 实机验证通过：项目增删多个目录、无项目任务移入项目及跨项目移动均正常。注：将已有任务“移出项目”变回无项目状态不在桌面端与后端既有设计范围内——`ProjectSidebarNode` 仅提供移动到目标项目，`moveTask` 接口 `projectId` 为必填非空字符串且校验目标项目存在，“不在项目中工作”仅用于新建无项目会话草稿，并非独立 Web 缺陷）。
- **记忆目录展示、正文页内查看与编辑保存，以及个性化指令门禁**
  - **症状**：独立 Web 此前因桌面门禁隐藏了服务端项目记忆目录与用户级 `AGENTS.md` 个性化指令；且官方原有“记忆”分区仅提供文件列表与调用本机外部编辑器（无删除接口），独立 Web 下无法在网页内直接查看或编辑记忆正文。
  - **状态**：已修复（按服务端能力开放项目记忆目录列表与服务端个性化指令读写；本仓新增记忆 Markdown 页内预览、编辑与保存，2026-11-12 实机验证通过）。
- **Node 发行包内置插件与内置技能资源缺失**
  - **症状**：独立 Web / Server 的 Node 打包与运行产物缺少内置插件、内置技能等随包资源，导致服务端运行时无法加载对应内置资源。
  - **状态**：已修复（2026-11-12 实机验证通过：内置官方插件与 `dynamic-workflows` 等内置技能资源齐全可用）。
- **安装与配置范围“用户 / 本机”表述歧义**
  - **症状**：插件、技能等配置范围沿用桌面端“用户 / 本机”文案，在独立 Web 下易与访问者浏览器所在设备混淆。
  - **状态**：已修复（2026-11-12 用户反馈已修改：新增 `settings.scope.server`“当前服务器”文案，独立 Web 下 `PluginScopeMenu`——插件、技能、命令、Hooks、子代理、MCP 共用——将当前服务器承载的“本机 / 用户”及“本机 · 用户”触发器统一显示为“当前服务器”，技能页“个人 / 用户”显示为“当前服务器”；其他远端设备分组仍保留其设备名与“用户”标签，记忆页项目选择器未改动，个性化指令此前已是服务端说明）。
- **归档、取消归档、删除任务失败及旧会话复活**
  - **症状**：归档、取消归档或删除任务时报 `Unknown channel`，或删除任务后刷新、重新打开页面时旧会话重新出现。
  - **状态**：已修复（用户确认）。
- **项目创建（无目录自动分配 / 单目录）与非项目工作模式报错**
  - **症状**：新建项目（含不选目录自动分配与单目录创建）或切换到“不在项目中工作”时，界面直接报 `remote-single-root-required`、`remote-project-required` 等错误码。
  - **状态**：已修复（用户确认；多目录项目与任务跨项目移入/移动见上方“任务移入项目、跨项目移动与项目多目录（多 root）限制”）。
- **系统原生剪贴板长文本粘贴转附件**
  - **症状**：独立 Web 粘贴 ≥15360 字符文本时调用缺失的桌面临时文件接口，导致文本既未进入输入框也未生成附件。
  - **状态**：已修复（Web 端改走内存 `File` 附件上传路径；16000 字符样本经系统原生剪贴板实测，用户反馈已转为附件）。
- **任务分组排序与移出分组失效**
  - **症状**：独立 Web 下新建分组、拖动任务排序或将任务移出分组不生效，刷新后顺序丢失或报 `task-group.host-identity-mismatch`、`project.host-offline`。
  - **状态**：已修复（统一使用服务端权威身份读写分组与删除记录）。
- **手机工作区与设置页布局、导航、说明列及 Switch 尺寸**
  - **症状**：手机窄屏下工作区与设置页沿用桌面双栏与 192px 控件列，说明文字被挤成窄列、缺少设置列表到详情的返回导航、Switch 控件被拉伸变形、触控高度不足 44px。
  - **状态**：已修复（接入手机 Home/Chat 导航壳层，设置页改为单栏列表→详情结构，说明在上控件在下，保持 Switch 原始尺寸与 44px 触控区）。
- **手机设置列表顶部留白过大**
  - **症状**：手机设置列表页沿用桌面窗口 48px 拖拽留白，返回按钮与列表整体偏下。
  - **状态**：已修复（移动端单栏设置列表移除桌面拖拽留白并收敛返回栏上下间距）。
- **手机子代理颜色选中圈偏移**
  - **症状**：手机端颜色单选按钮触控高度增至 44px 后，24px 选中圈沿用固定 `top: 4px` 导致位置偏上、与色点不居中。
  - **状态**：已修复（选中圈改为垂直居中对齐）。
- **子代理授权来源截断与长命令遮挡按钮**
  - **症状**：权限确认框中子代理来源说明仅在悬停标题显示或被截断，展开长命令后挤压底部导致批准/拒绝按钮不可见。
  - **状态**：已修复（完整换行展示子代理类型与任务说明，采用有界滚动容器保证操作按钮可达）。
- **设置页内置子代理模型菜单触控尺寸过小**
  - **症状**：手机端设置页内置子代理（`general-purpose`、`Explore`）的模型与思考强度下拉菜单未透传移动视口标志，仍按桌面 32px 渲染。
  - **状态**：已修复（透传移动视口标志，菜单项统一为 44px 触控高度且不超出屏幕宽度）。
- **新建技能与插件试用预填后未进入聊天页**
  - **症状**：手机端在设置中点击“新建技能”或在插件详情点击“试用/示例”预填提示词后，停留在原页面未切换到聊天视图。
  - **状态**：已修复（触发预填后自动跳转至手机 Chat 页面并保留草稿）。
- **断线重连闪屏、焦点丢失与设置页跳回工作台**
  - **症状**：短暂断线重连时整页内容卸载闪烁、编辑器焦点丢失，或已打开的设置页在重连后被磁盘标签恢复逻辑切回对话页，以及点击“重试连接”被旧握手阻塞。
  - **状态**：已修复（稳定 `settingService` 与 `broadcastService` 引用，同 Host 跳过重复标签恢复与首次 Provider 门禁重跑，1500ms 延迟显示重连提示，手动重试立即取消旧连接代际）。
- **新建项目目录浏览默认起点**
  - **症状**：独立 Web 新建项目选择目录时未默认定位到工作区根目录。
  - **状态**：已修复（独立 Web 目录浏览器默认起始路径设为 `/workspace`）。

## 桌面专属能力边界（非独立 Web 缺陷）

- **Electron 内置浏览器与本机 Chrome 数据导入/清理**：访问者电脑 Chrome Cookie 导入、内置浏览器缓存清理与证书设置仅适用于桌面端 Electron 内置浏览器；独立 Web 已区分提示，服务端 Agent 的无头 Chromium MCP 正常可用。
- **原生桌面交互（GenUI 沙箱、系统托盘、本机 WSL 等）**：依赖桌面宿主桥接，独立 Web 按平台能力隐藏或给出说明，不伪装为桌面可用。
