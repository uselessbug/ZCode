# 独立 Web 标准推送服务（`web-push`）

承载独立 HTTP Host 的 VAPID（RFC 8292）密钥管理、RFC 8291（`aes128gcm`）载荷加密、设备订阅持久化与异步出站投递。依赖 Node 内置 `node:crypto`、`node:https`/`node:http`、`node:dns` 与 `node:net`，不引入第三方加密依赖。

## 不变量

- **密钥与订阅跨重建稳定**：VAPID 密钥对（`wx` 排他创建）与订阅记录（带文件锁的原子写）持久化在 `<appConfigDir>/web-push/`（权限 `0600`），容器升级重建后无需浏览器重新订阅。
- **出站安全边界（防 SSRF / DNS Rebinding）**：仅接受经格式与曲线校验的 HTTPS 推送端点（测试模式可显式放行回环地址），禁带凭据与私网/保留地址；默认传输在自定义 `lookup` 校验全部解析出的 IPv4/IPv6 后直连已校验 IP 并禁止任何 `3xx` 重定向。
- **旁路容错与自动清理**：所有事件投递异步执行并设超时，网络或厂商服务异常绝不阻塞会话回合、权限审批或定时任务结算；收到 `404` / `410` 时仅在订阅记录 `updatedAt` 未变化时移除失效订阅。
- **单记录预算与去重一致**：序列化消息控制在单条 RFC 8291 记录预算内（`<= 3600B` 明文 / `<= 4096B` 密文）；按 `eventId` 幂等抑制重复发送；定时任务接管的回合不重复发普通完成通知；交互在发包前被解决或中断时仅取消待发项，不发静默包。
